# Project Management Backend

## Short Description

A backend API for project management built with Node.js, Express, TypeScript, and MongoDB.  
Supports role-based access and user/project management for Admin, Manager, and User roles.

---

## Tech Stack

- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, Role-based access control
- **Password Security:** bcrypt
- **Tooling:** Prettier
- **Deployment:** Railway hosting

## Quickstart

### Prerequisites

- Node.js 18+
- npm
- MongoDB instance (local or cloud)
- `.env` file at the project root (sample `.env.sample` provided)

### Install

```bash
npm install

# Developement
npm run dev

# Build
npm run build

# Preview
npm run start
```
